## **Principle**
#### **安排休息时间**
>1. 少每30min休息5min
>2. 不要子任务完成后休息，在任务进程中小憩
#### **提高对无聊的忍受度**
>1. 手机放包里/电脑后
>2. 不要有状态洁癖
>3. 走神及时回来
>4. 没听懂记录下来 回去解决
>5. 听完一部分，再集中做笔记
#### **提高专注力**
>1. 周末可以消遣一下
>2. 多阅读 
#### **复盘** (笔记本)
>1.  学习知识
>2. 进展 & 问题
